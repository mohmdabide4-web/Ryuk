# بوت فعاليات جروب الأنمي (واتساب)

بوت يستقبل أوامر تقديم فعاليات بالخاص من أشخاص محددين (أدمن)، ويرسل نتيجة الفعالية جاهزة بالجروب.

---

## 1) قبل الرفع — عدّل ملف `config.js`

افتح `config.js` وحط:

- **ADMIN_NUMBERS**: رقم واتسابك (أو أرقام أكثر من شخص) بصيغة دولية بدون `+`
  مثال: لو رقمك `+966 5X XXX XXXX` تكتبه: `"9665XXXXXXXX"`

> ملحوظة: ما تحتاج تحط آيدي الجروب هنا مسبقًا — البوت يطلبه منك
> كل مرة تبدأ فيها فعالية جديدة (خطوة 5 تحت).

---

## 2) رفع المشروع على GitHub

من داخل مجلد المشروع:

```bash
git init
git add .
git commit -m "أول نسخة من البوت"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```

> ملحوظة: مجلد `auth_info` و `node_modules` مستثنيين تلقائيًا (موجودين بـ `.gitignore`) —
> ما يصير ترفعهم لأنهم يحتوون بيانات جلسة حساسة وملفات تلقائية.

---

## 3) الرفع على Railway

1. روح [railway.app](https://railway.app) وسجل دخول بحساب GitHub
2. **New Project → Deploy from GitHub repo** → اختر الريبو
3. Railway بيكتشف تلقائيًا إنه مشروع Node.js وبيشغل `npm install` ثم `npm start`
4. **مهم جدًا**: البوت يحتاج يحتفظ بجلسة تسجيل الدخول (QR) بين كل إعادة تشغيل،
   لأن Railway مساحة التخزين فيه مؤقتة تنمسح مع كل نشر جديد. عشان تحل هذي المشكلة:
   - روح لإعدادات السيرفس بـ Railway → **Volumes**
   - أضف Volume جديد واربطه بالمسار: `/app/auth_info`
   - هذا يخلي جلسة تسجيل الدخول تبقى محفوظة حتى لو عملت Redeploy

---

## 4) ربط رقم الواتساب (أول تشغيل فقط)

1. بعد ما يشتغل البروجكت على Railway، روح لتبويب **Deployments → View Logs**
2. بيطلع لك رمز **QR** بالـ logs (نص وأشكال)
3. افتح واتساب بجوالك → **الإعدادات → الأجهزة المرتبطة → ربط جهاز**
4. صوّر شاشة الـ logs اللي فيها الـ QR بكاميرا الواتساب
5. بعد الربط بيطبع باللوق: `✅ البوت متصل بنجاح بواتساب`

> بعدها ما تحتاج تكرر هذي الخطوة إلا لو انحذف مجلد `auth_info` أو سجلت خروج الجهاز من الواتساب.

---

## 5) كيف تستخدم البوت — فعالية الأعلام

من رقمك الأدمن (المسجل بـ `config.js`)، أرسل **بالخاص للبوت**:

```
تقديم علم
```

**البوت يطلب منك قائمة الأعلام** — أرسل رسالة وحدة فيها كل إيموجيات
الدول اللي تبيها بالفعالية، مثال:

```
🇲🇦 🇪🇬 🇸🇦 🇫🇷 🇧🇷
```

البوت يفهم اسم كل دولة تلقائيًا من الإيموجي نفسه (ما يحتاج تكتب الأسماء).

**بعدها البوت يطلب رابط أو آيدي الجروب** — أرسل رابط دعوة الجروب
(زي `https://chat.whatsapp.com/XXXXXXXX`) أو آيدي جاهز لو عندك (`xxxx@g.us`).
لو البوت مو منضم بالجروب، بينضم تلقائيًا من الرابط.

**بمجرد ما يوصل الرابط، الفعالية تبدأ فورًا**:
- البوت ينشر أول علم بالجروب بنفس الفورمات
- أي عضو يكتب اسم الدولة **الصحيح بالعربي** بالجروب، البوت يسجله بصمت (بدون ما يرد عليه)
  وينتقل تلقائيًا للعلم التالي
- الاسم يتقبل حتى لو بدون "ال" التعريف أو بجملة (مثلاً "اعتقد انها مصر" تنفع)
- لما تخلص كل الأعلام، البوت يرسلك **النتائج الكاملة بالخاص** (كل علم + مين جاوب صح)

**أوامر إضافية:**
- `الغاء` — يلغي التقديم وأنت بمنتصف إرسال القائمة أو رابط الجروب
- `انهاء الفعالية` — يوقف فعالية شغالة فورًا ويرسلك النتائج الجزئية لحد هذي اللحظة

---

## 6) إضافة فعالية جديدة لاحقًا (مثل "النسخ")

سوّي ملف جديد بمجلد `events/` بنفس شكل `alam.js`، وسجله بملف `events/index.js`.
كل فعالية مستقلة عن الثانية، فما راح تأثر على فعالية الأعلام.

---

## هيكل الملفات

```
whatsapp-bot/
├── index.js              ← الملف الرئيسي (تشغيل البوت وإدارة الرسائل)
├── config.js              ← إعداداتك (أرقام الأدمن)
├── game.js                ← إدارة حالة الفعالية الجارية (الدور، النتائج)
├── package.json
├── railway.json            ← إعدادات التشغيل على Railway
├── .gitignore
├── data/
│   └── countries.js         ← أسماء كل الدول بالعربي (ISO -> اسم)
├── utils/
│   ├── flags.js              ← فك شفرة إيموجي الأعلام لاسم الدولة
│   ├── arabic.js              ← مطابقة إجابات المستخدمين بمرونة
│   └── groupResolver.js        ← تحويل رابط الجروب لآيدي جاهز
└── events/
    ├── index.js                ← فهرس الفعاليات
    └── alam.js                  ← فعالية الأعلام (الفورمات الثابت)
```
